The index.html Code
HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- Metadata and page title -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>

    <!-- Main heading of the webpage -->
    <h1>Welcome to My First Webpage</h1>

    <!-- First subheading -->
    <h2>About Me</h2>
    <p>Hello! I am learning how to build websites using HTML and web development tools.</p>

    <!-- Second subheading -->
    <h2>My Favorite Hobbies</h2>
    <p>I enjoy coding, reading tech blogs, and exploring new development workflows.</p>

    <!-- Third subheading -->
    <h2>Get in Touch</h2>
    <p>Feel free to reach out to me via my GitHub or email address!</p>

</body>
</html>
Step-by-Step Instructions to Verify
Save the File: Save the code above into a file named exactly index.html.

Open in Browser:

Locate the file on your computer using your file explorer or terminal.

Double-click index.html (or right-click and choose Open with your preferred web browser like Chrome, Firefox, or Edge).

Check Requirements: Confirm that the title in the browser tab reads "My First Webpage", and that you see one main heading (<h1>) followed by three distinct subheadings (<h2>).
